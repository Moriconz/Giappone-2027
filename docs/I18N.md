# i18n — Internationalizzazione (it / en / ja)

Sistema leggero, senza dipendenze, con **fallback all'italiano** (nessuna stringa si rompe se una traduzione manca).

## Come funziona
- **`js/i18n.js`** (caricato presto, prima di `app-core.js`) espone:
  - `window.t(key, fallback)` → ritorna `dict[lang][key]` || `dict.it[key]` || `fallback` || `key`
  - `window.I18N` → `{ t, setLang(lang), applyStatic(), lang, supported:['it','en','ja'] }`
- Lingua persistita in `localStorage.lang`; default = lingua del browser se supportata, altrimenti `it`.
- **Selettore** `#lang-switcher` nell'header (🇮🇹/🇬🇧/🇯🇵).
- Al cambio lingua: `applyStatic()` ritraduce la shell + evento `langchange` → `app-core.js` ri-renderizza la vista attiva.

## Due modi per tradurre
1. **HTML statico** (in `index.html`): attributi
   - `data-i18n="key"` → testo, `data-i18n-ph="key"` → placeholder, `data-i18n-title="key"` → title, `data-i18n-html="key"` → innerHTML.
2. **Stringhe dinamiche** (nei moduli JS): `window.t('key', 'Fallback IT')` dentro i template string.

## Aggiungere una stringa (3 passi)
1. Aggiungi la chiave nei **3 dizionari** (it/en/ja) in `js/i18n.js`.
2. Usa `window.t('tua.chiave', 'Testo IT')` nel codice (o `data-i18n` nell'HTML).
3. Se è in una vista già aperta, il re-render su `langchange` la aggiorna; altrimenti si traduce alla prossima apertura.

- Shell: header, banner offline, meteo (widget+modale), schermata errore mappa, titolo sheet.
- Navigazione: 4 tab + menu drawer (9 voci).
- **Dettaglio POI** (`poi-section-builders.js`): stato aperto/chiuso, categorie, orari, indirizzo, GF confermato/probabile, caratteristiche (veg/cena/pranzo/alcol/takeaway/prenotabile), tempo consigliato, ingresso + CTA "Aggiungi all'itinerario".

- Itinerario: empty-share modal (titolo, heading, "Ho capito", "Aggiungi una tappa").
- GF Guide: placeholder ricerca, loading. (i contenuti frasi/tessera/cameriere sono già IT+JP.)
